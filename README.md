# 🎓 StudentHub — Student Management System

### A Modern Student Records & Academic Management Web Application

StudentHub is a modern, responsive Student Management System designed to help administrators organize and manage student academic records through a clean and intuitive dashboard.

The application provides a centralized interface for managing students, attendance, marks, courses, and academic information.

## 🎯 Project Objective

The objective of this project was to design and develop a practical student management interface that could be used by an educational institution to organize student information and academic records.

The system focuses on:

- Simplifying student record management
- Providing a clear administrative dashboard
- Organizing academic information
- Monitoring attendance and performance
- Creating an efficient user experience

## 🧩 Main Modules

### 🔐 Admin Authentication

A dedicated administrator sign-in interface provides access to the management dashboard.

### 📊 Dashboard

The dashboard provides an overview of important academic information including:

- Total students
- Average attendance
- Average marks
- Active courses
- Recent students
- Attendance by branch

### 👨‍🎓 Student Management

Administrators can manage student records including:

- Student name
- Student ID
- Course
- Academic year
- Contact information
- Academic information

### 📅 Attendance

The system provides attendance information and branch-level attendance summaries.

### 📝 Marks & Academic Performance

Student academic performance can be organized and displayed through marks and performance information.

### 📚 Courses & Branches

The application supports organizing students according to different courses and academic branches.

---

## 💾 Data Management

This standalone demo uses browser-based storage to maintain records between sessions.

Data can also be exported in JSON format for portability.

> **Note:** This version is a frontend/standalone demonstration. A production version can be connected to a backend such as Flask with SQLite or MySQL for centralized database storage, authentication, and multi-user access.
